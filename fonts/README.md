## 按字体收录

确定具体字体后，保留其原始文件、LICENSE/OFL 等许可、METADATA.pb、来源路径、固定版本和 SHA-256 校验值。另行记录中文/拉丁字符覆盖、字重、斜体、可变字体轴、适用位置和加载方式；未检测到的能力标为未知。

Google 的仓库主要提供可使用的二进制字体文件及元数据，不代表包含每套字体完整的字形设计源文件。设计源文件需要按字体追溯作者仓库。各字体的授权文件分别保留，不能统一改标为 MIT。

未经用户指示不做字体裁切、格式转换、字形修改或替换。按需收录具体字体，不自动复制整个 Google Fonts 集合。本次没有新增或替换任何网站字体，也没有把尚未下载的字体标为可离线使用。
